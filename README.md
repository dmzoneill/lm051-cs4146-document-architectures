Projects for the CS4146 Document Architectures module, from the LM051 Computer
Systems degree at the University of Limerick.

## Contents

- `project 1` and `project 2`: XML documents with JavaScript and XSLT. One
  project loads a film catalogue from `catalog.xml` and shows each film's
  details, such as synopsis, cast, directors, producers, runtime and price.

## Tech

- XML, XSLT, JavaScript and HTML

## Viewing

Open the HTML files in each project folder in a browser.
